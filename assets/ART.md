# Original pixel artwork

Meshyard's 16-color maps, Claude worker, Codex robot, props and paths are original
code art in `app/src/playground/sprites.ts` and `yard.ts`. No game assets are used.

`meshyard-icon.svg` is the original 64-unit pixel icon, consumed by `npm run icons`.
All files in `app/src-tauri/icons` are generated by the Tauri icon tool.

`dmg-background.svg` is the 640×440 original installer background source.
`node scripts/render-dmg-background.mjs` renders the background PNG using local
Pixelify Sans via an isolated Chrome context on APFS. The source remains editable;
its SVG text fallback is monospace, while the generated PNG uses Pixelify Sans.
The PNG has no dependency on a font installed on the recipient's Mac. Place the
app and Applications icons near (160, 220) and (480, 220), respectively, in Phase 3.

Pixelify Sans is a third-party font under the SIL OFL 1.1, with the exact license
and source retained in `app/src/assets/fonts/`. Body/diff fonts are system fonts.
