## Implemented result

The working application now uses a shared sixteen-colour pixel system throughout setup,
workspace, errors, PartialCreate repair, saving/disabled controls and the static loading sign.
The background has a 4px dither; frames carry plank strips, notched corners and hard shadows;
forms are inset wells; controls have hard edges, pressed offsets and disabled hatching;
state/provenance badges are square tags. Text has solid backing. Controls are at least 48px
by source, focus uses a 4px yellow outline, and reduced motion suppresses press movement.
System monospace labels and English product strings retain the existing language decision.
There are no remote fonts, external assets, rounded cards, blurred shadows, theme framework
or new dependencies. These are source findings, not screenshot acceptance.

The yard is first and full-width above the two-column agent/member/profile sections. It
renders the environment even with zero agents, with the existing honest registration sign
and no invented characters. Original 16px grass tiles, connecting paths, trees and eight
station props are drawn with Pixi Graphics. Arrival receives null/No-events agents; the other
stations correspond only to Thinking, Building, Testing, Merging, Finished, Idle and Error.
There are no Reviewing/Fixing/WaitingForInput workstations. Every real AgentView produces
exactly one original character, coloured by kind, and a solid HTML nametag. Names truncate
visually only; complete names and unchanged activity/provenance are in the same-data AgentList.

Pixi remains pinned at 8.22.0, uses the existing static no-eval polyfills, nearest texture
sampling, roundPixels, resolution 1, no antialiasing and a single render without animation.
Each plot is 320×176 logical pixels on a 16px grid. ResizeObserver reapplies an integer CSS
scale and is disconnected through the existing scene lifecycle. No canvas text or font
rasterization is needed. The canvas and overlay remain aria-hidden. Renderer errors still
point to the complete accessible agent list.

The real App/typed-client flows, four command signatures, create/reopen/profile/register,
all eighteen typed errors and advice, PartialCreate repair and no-identity-fallback behavior
remain intact. No Rust, wire, security, CSP, generated binding or dependency file changed.
Registration still means **No events yet**, without fabricated Idle/Verified/activity/peers.
Existing serialized mutations and heading/input focus behavior remain in place.
