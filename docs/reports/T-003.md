## Files and production behavior

  ALPN dispatch, ping, diagnostics, selected-path watcher and redacted errors/Debug.
- `src/frame.rs`: the existing frozen `FrameHeaderV1`, header validation before allocation,
  256 KiB cap, 10 s initial / 120 s live deadlines, 16 KiB / 30 s pair cap/deadline,
  bounded writes and shared ingress budget. No event/genesis bytes are decoded or rewritten.
- `src/limits.rs`: four connections and sixteen streams per authenticated device across all
  connections/directions; 1 MiB/s application ingress with 4 MiB burst. Idle rate buckets survive
  rapid reconnects, and can be evicted only after full refill. Budgets and retained peer diagnostics
  have an additional 256-entry bound; incoming handshake/handler tasks are bounded too.
- `src/portmap.rs`: direct exact `portmapper 0.19.3` client, bound IPv4 UDP port,
  network-change watcher, external-address watcher, remove-before-add replacements,
  removal on expiry/network change/shutdown. Network changes take priority over queued grants
  and replace the source generation. Tests inject events and a separate clock trait driven by Tokio virtual time; they never
  construct the real router client.
- `src/tests.rs`: loopback-only direct, local relay and Strict suites; admission read counter,
  workspace rejection, default-closed sync, connection cap, invalid headers and actual endpoint
  mapping candidate lifecycle. Pure payload tests preserve postcard encoding/trailing-byte rejection.
- `Cargo.toml` and generated `Cargo.lock`: dependencies/features below.

`NetConfig` defaults to deny-all admission and no future protocol handlers. Strict requires an
explicit disabled relay choice; contradictory configuration is rejected. Strict starts from
`presets::Minimal`, disables relays and iroh's own mapper, clears all address lookup/publishing,
and uses `NetReportConfig::minimal()`. It never calls `online()`. The raw Endpoint is private, so
callers cannot insert relay/lookup services later. Explicit bind addresses remove both default
IP transports before binding the requested address. Ticket candidates use current `Endpoint::addr()`
IP addresses, including injected mapper advertisements. Callers must derive workspace/mode from
verified genesis when integrating T-005/T-006; this crate does not invent persisted workspaces.

Auto is an explicit config input: N0 for development, or a caller-supplied custom map. Custom
starts from Minimal without lookup. There is no automatic fallback on any failure. The
`strict-only` feature removes N0 construction and rejects Auto **before socket bind**. It does
not prove absence of n0 strings in a final T-013 app bundle; that release artifact is not built here.

Ping uses v1 headers with ALPN-local frame types 0 (request) and 1 (response), postcard timestamps,
exact payload consumption and a monotonic local RTT. Its path is the **selected local send path
sampled at request send time**. Diagnostics copy owned data out of `paths()`/`paths_stream()`;
no borrowed Path crosses tasks. Closing sessions remove their live path, retaining last-seen/error
history. Concurrent sessions keep their own selected paths. This does not assert the receive path
of every byte. No project tracing was added; secret-bearing configs/nodes have custom Debug and
errors contain fixed advice, never third-party error chains or secret/path/command data.

`for_workspace` refuses an inactive workspace or nonmember before exposing sync streams. The
T-006 handler must decode/validate Hello and use that gate for its actual workspace. T-005 must
provide real invitation authority/session/token handling. No fake Welcome, sync or pairing is served.

`close()` waits for mapper advertisement cleanup, stops the router and closes the endpoint before
releasing the process lease. Drop schedules the same ordering while a runtime exists. If dropped
outside a runtime, the process lease deliberately remains closed rather than permit an unobserved
second endpoint; applications must call `close()` before runtime teardown. Unit fixtures alone
bypass the process lease to create several in-process endpoints; production `bind()` does not.

Mapping diagnostics are `Disabled`, `Probing`, `Mapped { external }`, or
`NotObserved { after_secs: 10 }` after the bounded observation window. Repeated empty observations
do not postpone that window. These states never imply a router refused a request. The mapper's
`deactivate()` is a queued upstream operation with no public completion acknowledgment; actual
router lease deletion/granting has not been tested or claimed. Externally advertised candidates
are explicitly removed before endpoint close regardless of that router-side limitation.

### TLS proof and limits

The independent harness first completes a real in-memory rustls QUIC handshake and receives
session tickets from an early-data-enabled server. Each second connection **must expose client
0-RTT keys**, including the rejection branch: absence of a ticket cannot satisfy this proof.
The client config/session store and cloned server certificate resolver/session store/ticketer
are retained across each initial/resumed handshake; only the server early-data limit changes.

Positive control (`u32::MAX`): the resumed server exposes early keys while still handshaking,
decrypts an actual AEAD-encrypted marker into the test mutation counter, and the client reports
early data accepted. Negative (`0`): the capable client still produces the early encrypted
marker, but the server exposes no early keys, the pre-authentication mutation counter stays
zero, and the client reports rejection. **Both branches assert resumed handshakes**, not fresh
handshakes. The negative branch then completes authenticated 1-RTT and successfully encrypts,
decrypts and processes a retransmitted marker with the negotiated application keys. No claim
that rejected early data can never be retransmitted after authentication.

This is socket-free rustls QUIC/AEAD evidence and a test-only mutation callback. The vendor
builder test separately connects the disabled values to the actual iroh config construction.
It is not a live endpoint, router or cross-network acceptance claim. Standalone vendor tests
use the archive's unchanged lock (rustls 0.23.45); Meshyard's harness and endpoint test builds use
the project's pinned rustls 0.23.46 and patched iroh. Existing authenticated endpoint suites
still require execution in the parent's normal local-socket context after this change.
