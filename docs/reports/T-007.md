Implemented:

- `meshyard-hook <claude-code|codex> --socket <absolute path>`, silent exit 0
  on all handled errors. Empty stdin returns without a socket connection.
- One 150 ms supervisor budget starting at entry to `main`, 100 ms bounded stdin
  read, maximum 1 MiB, separate 20 ms connect and write waits clamped by remaining
  total time. Safe std worker threads bound blocking std I/O and metadata/JSON
  work; process exit terminates any detached blocked workers. There is no async
  runtime, signal handler, unsafe code, length prefix or environment socket lookup.
  This is not a hard real-time guarantee: OS startup/scheduling is observable in
  the external measurements below and precedes the first Rust `Instant`.
- Seven allowlisted event names, validated 1–128-byte ASCII IDs, optional invalid
  IDs omitted, invalid/missing session ID dropped, unknown fields discarded.
  Tool categories and the first-4-KiB command classifier are computed in hook
  memory. Both the parsed JSON and input buffer are dropped before socket I/O.
  Only a new allowlisted JSON object plus newline, at most 1 KiB, is transmitted.
  There are no prompt/path/cwd/hash/output/outcome fields or production logs.
- Socket and immediate parent checked with `symlink_metadata`; socket type,
  real parent directory, exactly `0700` permissions, and **both** owner UIDs
  compared with the effective UID from `rustix::process::geteuid().as_raw()`.
  Tests inject separate socket-owner, parent-owner and effective-UID mismatches.
  No actual other-user/root execution is claimed.
- `meshyard-agents::ingest::parse` decodes local envelope v1 into the actual core
  `AgentKind`, `HookEvent` and `ToolCategory`. Only `CommandClass` is a local enum.
  `StateMachine` takes explicit monotonic `Duration` values and returns the
  specified `(ActivityState, Provenance, Option<ToolCategory>)`.
- Per-agent-kind machines bound sessions to 32 with LRU eviction, ended turns to
  16 and duplicate tuples to 64 per session. Only `UserPromptSubmit` starts a
  turn; Idle/Finished/Error reject non-lifecycle traffic. Known ended-turn IDs
  and repeated identified tool events are rejected, including across turns.
  Subagent IDs distinguish duplicate contexts within the same registered agent.
- Stop produces Finished; the fake-clock 60-second expiry produces only Idle /
  Inferred{TurnEnded}. SessionEnd produces Idle / Verified{SessionEnd}; T-007b can
  derive the local "Session ended" description from that source. Staleness is a
  separate pure helper (age strictly greater than 600 seconds, excluding
  Idle/Finished). It never changes state or emits provenance. Reviewing, Fixing,
  WaitingForInput and RuleId::Stale are not produced.

## Fixtures and interpretation details

Fixtures are **scrubbed official-documentation-derived examples**, retrieved on
2026-11-03 from the [Claude Code hooks reference](https://code.claude.com/docs/en/hooks).
The fixture README links each event's exact input section. Their version scope
is rolling unversioned documentation, not evidence from an installed CLI version.
No live session was read or captured. Commands, prompts, paths, transcript
locations, output and file contents were removed. Synthetic classifier commands
and privacy sentinels are separate test-source inputs, not claimed captures.
KQ-003 outcomes are absent, with no claimed verified outcome evidence.

Bounded duplicate interpretation: identified tool tuples survive new prompts.
Entries without a `tool_use_id` are cleared at a new turn; otherwise a documented
ID-less UserPromptSubmit/Stop tuple would permanently suppress later real turns.
An ID-less prompt starts a new turn; indistinguishable ID-less prompt replays
cannot be reliably recognized. The classifier respects quoted/escaped separators
and discards `cd` segments; it is a bounded heuristic, not a shell interpreter.
Older Finished-session expiry updates that session internally but does not
replace a more recently updated session as the registered agent's current state.
These reversible local details are covered by tests and require reviewer attention;
no protocol/wire expansion was made.
