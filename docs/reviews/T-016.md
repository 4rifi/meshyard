- **Persistent scene:** `createYard(host, onError) → { update, destroy }`; characters keyed by
  `AgentView.id`, created once (arrival pad), updated in place, removed when the id disappears;
  station slot reservations are per id and independent of DTO order; empty visited plots are
  retained so other ids do not shift.
- **Motion:** pure path graph from plot geometry (doors, row-pair paths, left lane in 2-column);
  `walkRoute` at 48 logical px/s capped at 3 s; `step` measured from the route origin (no
  frame-rate drift); retarget mid-walk re-plans from the current position (frame shows the character
  leaving the path towards the new station without a jump); 2-pose step from the existing sprite and
  palette; ticker runs only while someone walks (`syncTicker`); reduced motion and layout reflow snap
  without inventing transitions.
- **Honesty:** only DTO state changes move characters; no idle wandering, peers or fake activity;
  unchanged agents stay put (the "unchanged" fixture agent remains on Arrival in every frame).
- **Cleanup:** destroy stops/removes the ticker, disconnects the ResizeObserver and media listener,
  clears maps, removes the HTML overlay and destroys the Pixi app; `update` after dispose is a no-op.
- **Scope:** frontend playground + yard effect only; no Rust/IPC/CSP/dependency/palette change.
- Accessibility unchanged: canvas `aria-hidden`, full names and states in the agent list, tag
  `title` carries name · state.

   the station width (two-line "test runner"). Make the width depend on occupancy: when an agent is
   the only character reserved at its target station, use the station tag width as in T-015
