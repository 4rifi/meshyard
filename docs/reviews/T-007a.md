## Required changes
1. **ID-less tool events are wrongly suppressed as duplicates.** The duplicate key is
   `(event, tool_use_id, agent_id)`. When `tool_use_id` is absent, every later `PreToolUse` of the
   same turn has the key `(PreToolUse, None, None)` and is dropped — e.g. Edit then `cargo test`
   stays Building instead of Testing. An absent ID is not an identity. Fix: record and check the
   duplicate key **only when `tool_use_id` is present** (lifecycle events are already handled by the
   turn/inactive rules). Add a test: two `PreToolUse` without `tool_use_id` in one turn (edit, then
   shell+test) → Building then Testing; identical event *with* the same `tool_use_id` still dropped.
2. **Guarantee "print nothing" on panics.** A panic in a worker thread would print the default
   panic message to stderr. Install a silent panic hook at the start of `run`
   (`std::panic::set_hook(Box::new(|_| {}))`); no other behaviour change. No test needed beyond
   existing ones.
