## Required changes
1. **Mobile yard is too small to read (375 px).** In the viewport image the 4-column 320-logical yard
   drops to scale 1: station titles and name tags are ~11 CSS px, characters 16 px, names cut to
   "test runn…" / "review co…". The accessible list helps, but the map — the visual centre — is
   uncomfortable to read. Fix per spec amendment "Responsive yard": below a 640 px host width use a
   **2-column station layout** (same 8 stations, same order, same real data) at integer scale ≥ 2;
   name tags may wrap to 2 lines before an ellipsis (also on desktop, where "test runn…" is cut
   too). No overflow, no fake activity.
2. **Background seam on short screens.** In error and loading (960×680) the checker texture stops
   below the content (≈ y 460 / 360) and the rest of the window is flat. Put the texture on the root
   (or give `body` `min-height: 100vh`) so every screen is textured to the bottom.
3. **Product copy must not expose internal task names.** Replace "Live status arrives when the Claude
   Code hook is installed (T-007)." and the footer "No networking or live hook in this slice" with
   plain, truthful text, e.g. "Live agent status is not connected yet." / "Local data only ·
   Networking and live agent status are not available yet." Show provenance in plain words with the
   same meaning (e.g. "INFERRED · SHELL TOOL", "VERIFIED · STOP EVENT") instead of raw enum names
   ("TOOLSHELL"). No change to what is claimed.
4. **Register action is below the fold** on the first desktop viewport (header + yard fill it) and
   far down on mobile. Add one visible "Register agent" control in the workspace title bar that moves
   focus to (and scrolls to) the **existing** agent-label input. Same form, same backend call; no new
   flow.
