# Pixelify Sans

Local unmodified variable TrueType font from Google Fonts:
https://github.com/google/fonts/tree/main/ofl/pixelifysans

Downloaded 2026-11-05 from `PixelifySans[wght].ttf` and `OFL.txt` in that directory.
Copyright and exact SIL Open Font License 1.1 are retained in OFL.txt.
Used for headings, controls and map labels. Body text and diffs keep readable
system sans/monospace fonts; no runtime network/font dependency.
